# LootKeeper

Chrome / Edge 擴充套件，每天定時自動領取遊戲 VIP 禮包。

> 作者：**墨染楓**（瑤光聽雪）

---

## 功能

- 每天在設定時間自動開啟禮包頁面，依序領取所有可領取的禮包卡片（日禮包、週禮包、月禮包、賽季禮包等）
- **開機補領**：若排程時間瀏覽器未開啟，下次啟動時自動補領當天
- **手動觸發**：隨時點擊工具列圖示立即領取，無次數限制
- 領取完畢後自動關閉禮包分頁（可調整）
- 執行記錄：保留最近 N 次結果，含各禮包的領取狀態
- 逾時保護：頁面 25 秒內未回應則自動關閉並記錄錯誤

> **注意：** 必須先在瀏覽器登入遊戲帳號，擴充套件才能正常運作。

## 安裝

### 1. 解壓縮

將下載的 ZIP 檔解壓縮到一個**固定位置**（例如 `Documents\LootKeeper`）。

**解壓後的資料夾不可刪除**，瀏覽器會持續從此路徑讀取套件檔案。若需要搬移，請參閱[移動安裝資料夾](#移動安裝資料夾)。

### 2. 載入擴充套件

**Chrome**
1. 網址列輸入 `chrome://extensions`，按 Enter
2. 右上角開啟「**開發人員模式**」
3. 點擊「**載入未封裝項目**」→ 選擇解壓縮後的資料夾
4. 頁面出現「LootKeeper」卡片即完成

**Microsoft Edge**
1. 網址列輸入 `edge://extensions`，按 Enter
2. 左側開啟「**開發人員模式**」
3. 點擊「**載入解壓縮**」→ 選擇解壓縮後的資料夾
4. 頁面出現「LootKeeper」卡片即完成

## 初次設定

自動排程需要瀏覽器在背景持續運作。建議完成以下兩項設定。

### 背景執行

關閉瀏覽器視窗後，排程預設會停止。開啟背景執行可避免此問題：

**Chrome**
設定 → 系統 → 開啟「**關閉 Google Chrome 後繼續執行背景應用程式**」

**Edge**
設定 → 系統與效能 → 開啟「**關閉 Microsoft Edge 時繼續執行背景延伸模組和應用程式**」

### 開機自動啟動

**雙擊 `setup.bat`**（若出現 UAC 提示或錯誤，請右鍵 → 以系統管理員身分執行）

腳本會自動偵測已安裝的 Chrome / Edge，並建立 Windows 工作排程器項目，使瀏覽器隨開機啟動。完成後重開機即生效。

> 兩項設定完成後，即使關機也能確保隔天定時執行。

## 使用方式

點擊瀏覽器工具列的套件圖示開啟控制面板。

### 控制面板

| 元件 | 說明 |
|------|------|
| **立即領取** | 手動觸發，無次數限制 |
| **記錄 tab** | 顯示最近 N 次執行結果 |
| **🗑（清空）** | 清除所有執行記錄 |
| **設定 tab** | 調整自動化行為 |
| **贊助 tab** | 支持作者 |

### 設定選項

| 項目 | 說明 |
|------|------|
| **每日自動領取** | 關閉後停止排程，僅保留手動領取 |
| **每日執行時間** | 開啟自動領取後顯示；修改後按「儲存」立即重新排程（預設 05:10） |
| **領取後關閉頁面** | 完成後是否自動關閉禮包分頁（預設開啟） |
| **歷史紀錄筆數** | 保留幾筆記錄（1–50，預設 3；超過 5 筆時列表出現捲軸） |

### 記錄說明

**卡片左側顏色**

| 顏色 | 意思 |
|------|------|
| 綠色 | 全部成功 |
| 橘色 | 部分成功 |
| 紅色 | 執行失敗 |

**單項標籤**

| 標籤 | 意思 |
|------|------|
| ✓ 成功 | 禮包領取完成 |
| 已領過 | 今日已領，自動跳過 |
| 未解鎖 | 該禮包尚未解鎖 |

## 更新擴充套件

前往 `chrome://extensions` 或 `edge://extensions`，點擊「LootKeeper」卡片上的「**重新載入**」即可套用新版本。

---

## 移動安裝資料夾

直接搬移資料夾後，瀏覽器會無法讀取套件，擴充套件將顯示錯誤並停用。請依照以下步驟重新安裝：

1. 前往 `chrome://extensions`（或 `edge://extensions`），移除「LootKeeper」
2. 將資料夾搬移到新位置
3. 重新點擊「**載入未封裝項目**」，選擇新路徑下的資料夾
4. 若原本有設定開機自動啟動，重新執行一次 `setup.bat`

---

## 完整移除

1. 前往擴充套件頁面，點擊「**移除**」
2. 雙擊 `remove.bat`，移除 Windows 工作排程器中的開機啟動項目
3. 刪除安裝資料夾

移除後不會有任何殘留。

## 常見問題

**Q：安裝後沒有自動領取**
A：請確認已完成「初次設定」的背景執行與開機自動啟動兩項設定，且「每日自動領取」開關已開啟。

**Q：手動開啟禮包頁面，自動領取不會執行**
A：套件僅在自己開啟的分頁中執行，直接輸入網址開啟不會觸發。這是刻意的安全設計。

**Q：記錄顯示「找不到禮包圖示」**
A：頁面未正常載入，最常見原因是尚未登入遊戲帳號，請先在瀏覽器完成登入。

**Q：記錄顯示「逾時（25 秒內頁面未回應）」**
A：頁面載入過慢或網路不穩。可稍後手動點擊「立即領取」重試。

**Q：搬移資料夾後套件顯示錯誤**
A：參閱上方[移動安裝資料夾](#移動安裝資料夾)。
